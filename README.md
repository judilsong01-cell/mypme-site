# MyPME Public Site

Website estático público do MyPME, preparado para GitHub Pages.

O MyPME é uma aplicação Android de gestão para micro e pequenas empresas em Angola. Este repositório contém apenas HTML, CSS, SVG e ficheiros públicos de apoio. Não contém o código da aplicação, credenciais, dependências npm, trackers ou formulários de recolha.

## Conteúdo

- `index.html`: apresentação do produto.
- `privacy-policy.html`: política de privacidade.
- `account-deletion.html`: processo de eliminação de conta e dados.
- `support.html`: orientação e contacto de suporte.
- `app-ads.txt`: declaração pública do publisher para Google AdMob.
- `robots.txt` e `sitemap.xml`: preparação para indexação.
- `assets/`: ilustrações SVG locais e originais.
- `GITHUB_PAGES_DEPLOYMENT.md`: instruções de publicação manual.
- `SITE_VALIDATION_REPORT.md`: validações realizadas e pendências.

## Pré-visualização local

Abra `index.html` diretamente num navegador. Não é necessário servidor, Node, npm ou processo de build.

## Antes da publicação

Substitua todas as ocorrências de `SEU-USUARIO` pelo nome de utilizador ou organização GitHub que efetivamente publicará o repositório. O endereço `https://SEU-USUARIO.github.io/mypme-site/` é apenas um placeholder documentado e não representa um website já publicado.

Depois da substituição, valide novamente ligações, canonical, `robots.txt` e `sitemap.xml` seguindo [GITHUB_PAGES_DEPLOYMENT.md](GITHUB_PAGES_DEPLOYMENT.md).
